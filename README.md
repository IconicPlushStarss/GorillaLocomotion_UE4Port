# Gorilla Locomotion for Unreal Engine 4

Experience Arm-Based Swinging Locomotion. But In Unreal.

## Extra Features

- Out Of The Box Haptic Support.
- Player Model Support.
- Example Level.
- Multiplayer Replication.
- Modified UE4 Mannequin + Animation Blueprint. 

## Extra Infomation:

- No C++, All Blueprint Code.

> **Disclaimer.** Since this is a recreation of the original code base, it is **client-authoritative** movement.

> ~~**Second Disclaimer.** This will not work on **listen-servers**.~~ This has now been fixed.

## How to Use

Note: **This Port Was Made With `Unreal Engine 4.27.2`**

1. Click **Code** and download the `.zip` file.
2. Extract into your unreal projects content folder.
